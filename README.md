# Bigger Bucks

Tap the pile with more money. Count coins and bills before the timer snaps.

## How to play

- Two trays of coins and bills appear. One is worth more.
- Tap the richer pile before the bar runs out.
- Three misses and the run ends. Streaks add bonus points.

Sound unlocks on Play. Mute lives in the HUD.
